# DESIGN SYSTEM — Pixel Office

- **Direction artistique** : Rétro Pixel Art Top-Down 3/4 (inspiration Pokémon GBA / Kairosoft) combiné aux couleurs signatures Agence Bulles.
- **Palette** :
  - Primaire Agence Bulles (`lead-dev`) : `#D81B60` (Rose Framboise)
  - Secondaire Agence Bulles (`ops-quality`) : `#134242` (Teal Profond) & `#C2E8E8` (Menthe Glacée)
  - Tertiaire (`integrations`) : `#F59E0B` (Ambre Paiements)
  - Fond Kiosk Second Écran : `#0B0F19` / `#111827`
  - Parquet Open Space : `#C89D66` / `#BF925B`
- **Typographie** :
  - Titres & Badges HUD : `'Press Start 2P', monospace`
  - Bulles & Logs temps réel : `'VT323', monospace`
- **Règles d'interface** :
  - Zéro emoji structurel dans l'interface HTML.
  - Bulles HTML superposées au Canvas pour garantir une netteté de lecture parfaite sur écran secondaire.
  - Cadence Canvas limitée à 18 FPS.
