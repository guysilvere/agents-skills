# Bibliothèque DESIGN.md — références de sites réels

> Source : voltagent/awesome-design-md (73+ DESIGN.md analysés, format Google Stitch).
> Usage : copier le DESIGN.md d'un site dans le projet, dire à l'agent « construis une page qui ressemble à ça ».
> ⚠️ Ne PAS copier les fichiers dans le repo — référencer par lien (anti-redondance).

## Comment récupérer un DESIGN.md
- `https://getdesign.md/<slug>/design-md` → le fichier DESIGN.md
- Chaque dossier contient aussi `preview.html` + `preview-dark.html` (catalogue visuel : couleurs, type, boutons).

## Formats utiles pour les SaaS
- **Fintech / paiement** : Stripe, Revolut, Wise, Coinbase, Mastercard.
- **SaaS product / dashboard** : Linear, Notion, Supabase, PostHog, Sentry, Raycast.
- **Landing marketing** : Vercel, Shopify, Intercom, Framer, Webflow.
- **Dark tech / AI** : OpenCode (`opencode.ai`), xAI, Replicate, ElevenLabs, Together AI.
- **Éditorial** : WIRED, The Verge (si refonte éditoriale).

## Règle d'usage
1. Choisir 1 référence alignée au Design Read (jamais « copier » mais « s'inspirer »).
2. Extraire les tokens (couleurs, type, composants) → les figer dans MASTER.md.
3. Ne jamais mélanger 2 références sur la même page sans raison documentée.
