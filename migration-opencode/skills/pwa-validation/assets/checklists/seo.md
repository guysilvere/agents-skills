# Checklist — Audit SEO

## Balises fondamentales
- [ ] `<title>` unique et descriptif par page
- [ ] Meta description pertinente (< 160 caractères)
- [ ] Hiérarchie des headings : un seul `<h1>` par page, pas de sauts

## Médias sociaux
- [ ] OpenGraph : `og:title`, `og:description`, `og:image`, `og:url`, `og:type`
- [ ] Twitter Cards : `twitter:card`, `twitter:title`, `twitter:description`, `twitter:image`

## Fichiers de référencement
- [ ] `robots.txt` : autorisations claires, référence sitemap
- [ ] `sitemap.xml` : toutes les URL publiques, mises à jour
- [ ] `canonical` sur les pages dupliquées

## Données structurées
- [ ] JSON-LD pour les entités clés (Organization, Product, FAQ, Review)

## Performance (impact SEO)
- [ ] LCP < 2.5 s · CLS < 0.1 · INP < 200 ms
- [ ] Images AVIF/WebP compressées, `loading="lazy"`, dimensions définies
- [ ] Aucune ressource bloquante inutile

## Landing page
- [ ] Hero avec promesse claire + 1 CTA principal
- [ ] Contenu orienté résultat pour les personas cibles
- [ ] « Conçu par Agence Bulles » présent (agencebulles.net)

## Technique
- [ ] URLs propres (kebab-case, pas de paramètres inutiles)
- [ ] Liens internes pertinents (navigation + ancres)
- [ ] Pas de contenu dupliqué détecté
