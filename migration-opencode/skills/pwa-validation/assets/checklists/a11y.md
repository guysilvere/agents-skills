# Checklist — Accessibilité (a11y)

## Contraste & couleurs
- [ ] Contraste texte ≥ 4.5:1 (WCAG AA) — normal et grand texte
- [ ] Contraste UI / composants ≥ 3:1 (bordures, icônes, états)
- [ ] Aucune information transmise par la couleur seule
- [ ] Variante mode sombre testée séparément

## Focus & clavier
- [ ] Focus visible sur tous les éléments interactifs
- [ ] Ordre de tabulation logique (DOM)
- [ ] Pièges de focus évités (modales : focus entrant/sortant gérés)
- [ ] Raccourcis clavier ne bloquant pas la navigation navigateur

## Sémantique & ARIA
- [ ] Balises HTML5 sémantiques (`header`, `nav`, `main`, `footer`…)
- [ ] Landmarks ARIA si la sémantique ne suffit pas
- [ ] `aria-label` sur les icônes sans texte
- [ ] `aria-live` pour les annonces dynamiques (toasts, erreurs)
- [ ] Rôles ARIA corrects sur les composants custom (tabs, dialog, switch)

## Formulaires
- [ ] `<label>` explicite associé à chaque champ
- [ ] Messages d'erreur reliés au champ (`aria-describedby`)
- [ ] Placeholders non utilisés comme seul label

## Images & médias
- [ ] `alt` descriptif sur chaque image (ou `alt=""` si décorative)
- [ ] Transcriptions/sous-titres pour les médias

## Mouvement & réduction
- [ ] `prefers-reduced-motion` respecté
- [ ] Aucune animation bloquante (flash > 3 Hz interdit)

## Mobile & tactile
- [ ] Cibles ≥ 44×44 px
- [ ] Zoom non désactivé (`user-scalable=no` interdit)
- [ ] Orientation paysage utilisable

## Tests
- [ ] Vérifié au clavier uniquement (navigation complète)
- [ ] Vérifié avec lecteur d'écran (basique)
- [ ] Taille de texte système au maximum sans casse
