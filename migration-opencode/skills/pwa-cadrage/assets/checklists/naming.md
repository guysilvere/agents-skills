# Checklist — Naming

## Critères de qualité (chaque candidat)
- [ ] Court et prononçable
- [ ] Mémorable, sans ambiguïté
- [ ] Aucune connotation négative en FR et EN
- [ ] Extensible (ne bloque pas les évolutions futures)
- [ ] Pas générique, pas une mode éphémère

## Techniques de génération
- Mot-valise / métaphore / mot réel détourné / néologisme court / préfixe-suffixe

## Vérifications de disponibilité
- [ ] Domaines : Namecheap, Instant Domain Search, Whois (`.app .net .ci .com .dev`)
- [ ] Stores : Google Play Console, Apple App Store Connect
- [ ] Marques FR : INPI (data.inpi.fr)
- [ ] Marques Afrique francophone : **OAPI** (oapi.int — 17 pays dont la Côte d'Ivoire) — prioritaire en CI
- [ ] Réseaux sociaux : Namechk (30+ plateformes)
- [ ] GitHub : nom de repo non utilisé

## Livrables
- [ ] 5–10 propositions avec raison du choix + slogan d'une ligne
- [ ] Nom validé par l'utilisateur
- [ ] Dossier local `/Projets/<nom>` créé
- [ ] Domaine `.test` local assigné (Caddy)
